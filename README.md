## 🚀 Featured Projects

### [Kazini](https://kazini.brandonadhoch.dev) – Attendance and HR Platform
Full-stack platform for multi-site teams. Fingerprint scanners, GPS and QR check-ins feed a live site kiosk, an employee portal and an admin area for leave and site management.

### [The Riviera](https://riviera.brandonadhoch.dev) – Hotel Website and Booking System
Website and booking experience for a lakeside hotel on Lake Victoria, with a live date-and-rate booking flow.
**Stack:** Django, MySQL, Tailwind CSS, Alpine.js, deployed on AWS.

### [Jazz Symphonic](https://jazz.brandonadhoch.dev) – Editorial Platform
Web platform for Nairobi's classical music archive, built for editorial content and archive browsing.

### Palisade Health – Patient Portal
Next.js frontend for a preventive health clinic patient portal, built accessibility-first with component library documentation.
**Stack:** Next.js

### [.Paak Photography](https://brvndonadhoch.github.io/Paak-Photography/) – Portfolio Website
Responsive one-page site with a full-screen hero, photo grid, pricing packages and a contact form, hosted on GitHub Pages.
